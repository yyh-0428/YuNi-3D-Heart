# 予你 · A heart, for you

一个淡玫瑰色的人体心脏互动作品。模型由原创 Three.js 几何代码生成，配合心室收缩、轻微扭转、双拍心跳声与粉白页面。

## 本次更新 · 1.2

- 重做心跳声音：低沉、稍长的第一心音与更短、更轻的第二心音，使用带限组织共振和柔和的机械瞬态，保留自然的衰减与停顿。
- 增加 12 组细微音色变化，匹配各组响度，并加入轻微的呼吸式强弱变化；节拍本身保持稳定。
- 开启声音后，动画、示意心电曲线与心音共同跟随音频输出时钟。支持的浏览器使用输出时间戳补偿延迟；其他浏览器使用报告的基础及输出延迟估计。
- 暂停、静音和重新同步采用短淡出。恢复时从下一个可安排的完整节拍入拍，避免重复或孤立的第二心音。

## 已有功能 · 1.1

- 页面右上方新增「柔粉 / 真实」配色选择。柔粉保留原来的粉白观感；真实采用深红心肌、较暗的静脉和柔和的组织色差。切换不重置心率、视角或心跳，在浏览器允许时会记住选择。
- 重做心动周期：局部径向收缩、纵向缩短、心尖与基底间的轻微扭转，接着快速解扭、舒张与缓慢充盈；心房另有较轻的收缩阶段。
- 每周期只有一次心室收缩，第二心音对应舒张开始。重做了双组短促共振的心音，并让动画、心音与示意心电曲线共享时序。

## 直接打开

解压后，在浏览器中打开根目录的 **`index.html`**。它就是完整的单文件版本：Three.js、代码、样式、中文字形全部内嵌，没有 CDN、网络字体、外部模型、录音或后端依赖。

点击 **「听见心跳」** 开启声音。初始无声，避免突然播放；声音由 Web Audio 在本机合成。

| 操作 | 效果 |
| --- | --- |
| 右上方「柔粉 / 真实」 | 切换两种心脏配色 |
| 鼠标或单指拖动心脏 | 旋转观察，包括完整背面 |
| 滚轮 / 双指捏合 | 缩放 |
| 心率滑块 | 在 50–110 BPM 间调整；默认 72 BPM |
| 暂停按钮 | 同时暂停形变与心跳声 |
| 环绕 | 缓慢自动旋转 |
| 复位按钮 / 双击模型 | 恢复正面视角 |
| 方向键 / 加减键 / Home | 聚焦模型后旋转、缩放、复位 |

页面针对桌面、平板和手机宽度设置了不同布局。手机请使用可执行 JavaScript 的浏览器打开；文件管理器中的静态预览不等于网页运行。若手机不支持直接打开本地 HTML，可将 `index.html` 放到任意静态网页服务上，或使用下方的本地服务。

## 修改与离线构建

普通使用只需要浏览器。修改后重新构建需要 Node.js 18 或更高版本，不需要安装 npm 依赖：

```bash
node scripts/build.mjs
node scripts/check.mjs
```

构建会同时生成根目录 `index.html` 与 `dist/index.html`。修改 `src/`，然后重新构建即可；不要直接改压缩后的第三方库。

可选本地服务：

```bash
node scripts/serve.mjs
```

随后在电脑浏览器打开 `http://localhost:4173`。在同一局域网的手机上，可访问电脑的局域网 IP 加 `:4173`；是否可达取决于电脑的网络与防火墙设置。

只有在需要更新 Three.js 本身时，才需要联网安装打包依赖：

```bash
npm ci
npm run vendor:update
npm run build
```

## 模型与声音

模型采用约 10 万个顶点、18.8 万个三角面，合并为 5 个主要网格。心室主体为不对称参数曲面，心房与心耳独立塑形；大血管由有半径变化的空间曲线生成，冠状血管贴合实际心肌曲面。

血管同时使用半径渐细、颜色变浅和透明度渐隐。心脏轮廓通过柔和的掠射光变浅，保留实体感。心室与冠状血管共用局部形变场；心房和大血管分别使用较轻的收缩或牵引运动。法线跟随形变更新，让表面光照随真实的几何变化移动。

声音完全由代码合成，没有采集任何人的生物数据或使用外部录音。每种心音由带限噪声激发多组宽带组织共振，再经低频过滤、柔和起音与尾部衰减；第一心音低沉、稍长，第二心音更短、更轻。12 组音色有微小的频谱与包络差异，响度经过匹配，避免每一拍都像重复同一个机械音效。每拍还加入很轻的强弱变化，不随机改变心率。

动画和示意心电曲线每帧只采样一次共同的时钟。开启声音后，使用 `AudioContext.getOutputTimestamp()` 将画面跟随到正在输出的音频帧，而不是提前渲染的音频位置。没有有效时间戳时，退回 `baseLatency + outputLatency` 估计。心音在音频线程提前成对安排，第一声对应收缩开始，第二声对应舒张开始。

调整心率、暂停、恢复与切回页面时会重新同步。暂停和关闭声音带有 18 ms 的短淡出；恢复时从下一个可安排的完整心动周期入拍，视觉相位保持连续。浏览器或系统未报告的设备延迟、蓝牙额外缓冲与显示刷新仍可能造成误差；本项目没有测量具体设备的实际延迟。

这是参考人体解剖外形关系制作的爱情主题艺术模型，提供柔粉艺术配色与深红自然组织配色；不是医学扫描重建或临床仿真。
